# Changelog • История изменений Ggram

## [1.2.0-emerald] — 2026-09-03

### Добавлено:
- **Автоматические вкладки чатов (Smart Tabs)**:
  - Авто-разделение переписок на суб-вкладки: `Все` • `Личные` • `Группы` • `Каналы` • `Боты` • `Непрочитанные` (`GgramSmartTabsManager`).
  - Отображение точных счетчиков непрочитанных сообщений на каждой вкладке.
- **Шпионский инспектор профилей (User Profiler)**:
  - Расчет точного года регистрации аккаунта собеседника по его числовому Telegram ID (`estimateRegistrationDate`).
  - Детектор взаимного контакта: индикатор, сохранен ли ваш номер в записной книжке собеседника (`isMutualContact`).
  - История изменений имен и юзернеймов пользователя (`recordNameChange`).
- **Умная очистка диска и квот (Smart Storage Cleaner)**:
  - Индивидуальные квоты кэша на канал (по умолчанию 500 МБ) с авто-очисткой старых медиа при превышении (`GgramStorageCleaner`).
  - Выборочная очистка тяжелых файлов: отдельное удаление только видеокружочков, только голосовых или только стикеров.
  - Белый список избранных чатов для защиты от случайного удаления медиа.
- **Эргономика чтения и переписки (Chat Ergonomics)**:
  - Выделение и копирование части текста сообщения без копирования всего поста (`copyTextSnippet`).
  - Быстрая пересылка без указания оригинального автора в один тап (`stripAuthorQuote`).
  - Полное скрытие сообщений заблокированных пользователей в общих беседах и группах (`shouldHideGroupMessage`).
  - Мгновенный переход к первому сообщению в диалоге или канале.
- **Интеллектуальные уведомления**:
  - Фильтр «Только важные пуши»: уведомления приходят только на личные сообщения и прямые теги `@username`. Все реакции, истории и закрепы глушатся.
  - Ночной режим тишины: автоматическое отключение звука каналов с 23:00 до 08:00.
- **Исправление CI/CD**:
  - Обновлен рабочий процесс `.github/workflows/build-apk.yml` с автоматической установкой Gradle 8.2.2 через `gradle/actions/setup-gradle@v3` и сборкой APK.

## [1.1.0-emerald] — 2026-09-03
- Автоматизация CI/CD на GitHub Actions.
- AI & Free Telegram Premium Suite: Voice-to-Text, переводчик, саммаризатор.
- Безопасность и «Двойное дно»: Fake PIN, маскировка под «Калькулятор», цензурирование данных.
- Turbo Media Downloader: 4–8 потоковое скачивание, тихий захват медиа.
- Прокси менеджер с авто-пингом.
