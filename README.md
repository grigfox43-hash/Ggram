## ⚡ Ключевые возможности

### 🗂️ 1. Автоматические вкладки чатов (Smart Tabs)
- **Умное разделение диалогов:** Вкладки `Все` • `Личные` • `Группы` • `Каналы` • `Боты` • `Непрочитанные` прямо над списком чатов.
- **Точные счетчики:** Бейджи с количеством непрочитанных сообщений на каждой категории.
- **Кастомизация:** Возможность скрыть ненужные вкладки в один клик.

### 🔍 2. Шпионский инспектор профилей (User Profiler)
- **Определение года регистрации:** Автоматический расчет даты создания аккаунта по его числовому Telegram ID (от ветеранов 2013 года до новичков).
- **Индикатор взаимного контакта (Mutual Contact):** Сразу показывает, сохранен ли ваш номер в записной книжке собеседника.
- **История изменений имен:** Локальное сохранение старых имен и никнеймов пользователя при их смене.

### 🧹 3. Умная очистка памяти и диска (Smart Storage Cleaner)
- **Квоты кэша на каждый канал:** Ограничение размера кэша (по умолчанию 500 МБ) с авто-удалением старых медиа при превышении лимита.
- **Выборочная очистка:** Удаление только видеокружочков, только голосовых заметок или стикеров.
- **Белый список чатов:** Защита важных переписок от случайной очистки файлов.

### ✍️ 4. Эргономика чтения и переписки (Chat Ergonomics)
- **Копирование части текста:** Выделение и копирование конкретной цитаты или абзаца без копирования всего поста.
- **Чистая пересылка без автора:** 1-тап отправка чужого сообщения без плашки оригинального автора.
- **Скрытие заблокированных в группах:** Сообщения нежелательных людей полностью исчезают из ленты бесед.
- **Прыжок в самое начало:** Быстрый переход к первому сообщению в диалоге или канале.

### 🔕 5. Интеллектуальный контроль уведомлений
- **Только важные пуши:** Уведомления со звуком и вибрацией приходят только на личные сообщения и прямые теги `@username`.
- **Ночной режим тишины:** Автоматическое отключение уведомлений от каналов с 23:00 до 08:00.

### 🤖 6. AI и функции Telegram Premium (Бесплатно)
- **Voice-to-Text (Расшифровка голосовых):** Перевод входящих и исходящих голосовых и видеосообщений в текст без подписки Telegram Premium.
- **Встроенный переводчик:** Мгновенный перевод сообщений в чатах в один тап через Google Translate, DeepL или Yandex.
- **AI-саммаризатор:** Автоматическая генерация краткой выжимки ключевых мыслей из длинных публикаций в каналах.

### 🛡️ 7. 100% Блокировка рекламы (AdBlock Engine)
- **Удаление спонсорских сообщений Telegram:** Полная фильтрация `TL_messages_sponsoredMessages` на уровне сетевого протокола MTProto в публичных каналах.
- **Эвристический фильтр рекламных постов:** Автоматическое обнаружение и сокрытие рекламных публикаций в каналах (по меткам `#реклама`, `#ad`, `erid`, рекламным ботам).
- **Подавление промо-контента:** Отключение навязчивых баннеров Telegram Premium, предложений покупки Telegram Stars и подарков.

### 🔒 8. Безопасность: Система «Двойное дно» и маскировка
- **Двойной пароль (Fake / Panic PIN):** Возможность задать два PIN-кода. Основной открывает ваши реальные чаты, а ложный — открывает скрытый профиль без приватных диалогов.
- **Маскировка под «Калькулятор»:** Рабочий калькулятор на экране входа до момента ввода секретного кода.
- **Скрытие личных данных на скриншотах:** Автоматическое размытие номеров телефонов, номеров банковских карт и адресов криптокошельков.

### ⚡ 9. Turbo Media Downloader & Player
- **Многопоточное скачивание (4–8 потоков):** Ускорение загрузки файлов и видео размером до 4 ГБ с отображением скорости в реальном времени.
- **Бесшумный захват исчезающих медиа:** Сохранение самоуничтожающихся фото и видео с таймером без отправки собеседнику уведомления *«User took a screenshot»*.
- **Фоновое воспроизведение видео:** Непрерывное прослушивание кружочков и голосовых заметок при заблокированном экране или в режиме PiP.

### 🌐 10. Встроенный прокси и обход блокировок
- **Поддержка современных протоколов:** MTProto, Socks5, Shadowsocks и V2Ray без внешних VPN-приложений.
- **Авто-тест задержки (Ping):** Автоматический выбор узла с наименьшим пингом.

### 👻 11. Режим невидимки (Ghost & Privacy Suite)
- **Скрытое чтение (Ghost Read):** Читайте сообщения без отправки галочек прочтения собеседнику.
- **Прочтение только при ответе (Read on Reply):** Сообщения отмечаются прочитанными только тогда, когда вы сами отправляете ответ в диалог.
- **Скрытый ввод (Typing Stealth):** Блокировка статусов «печатает...», «записывает голосовое...» и отправки файлов.
- **Вечный Офлайн (Offline Status Lock):** Ваш аккаунт всегда отображается офлайн без обновления времени последнего визита.
- **Анонимный просмотр историй (Stories Ghost):** Просматривайте истории без появления вашего профиля в списке зрителей.
- **Защита от случайных действий:** Подтверждающие диалоги перед отправкой голосовых сообщений, видеокружочков, стикеров и вызовов.

### 💾 12. Сохранение сообщений (Anti-Recall & Message Spy)
- **Сохранение удаленных сообщений:** Удаленные собеседником сообщения не исчезают из локальной базы данных, а помечаются ярким красным бейджем `[Удалено]` с отметкой времени.
- **История редактирования сообщений:** Сохранение всех версий правок в чате с интерактивным просмотром различий `[Изм.]`.

### 🔓 13. Обход ограничений (Restrictions Bypass)
- **Разрешение скриншотов:** Снятие системного флага `FLAG_SECURE` — возможность делать скриншоты и видеозапись экрана в секретных чатах и каналах.
- **Снятие защиты от копирования (`noforwards`):** Разрешено копирование текста, пересылка сообщений и сохранение медиа в галерею из каналов с запретом от автора.

## 🛠️ Сборка и релизы

### Автоматическая сборка через GitHub Actions
При каждом коммите или создании тега в репозитории автоматически запускается сборка APK в облаке GitHub Actions. Готовый APK доступен для скачивания во вкладках **Actions** и **Releases**.

### Локальная сборка
```bash
# Клонирование репозитория
git clone https://github.com/grigfox43-hash/Ggram.git

# Переход в директорию
cd Ggram

# Сборка Debug APK
./gradlew assembleDebug
```
