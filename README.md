## ⚡ Архитектура и экраны клиента Telegram

### 📱 1. Авторизация и профиль
- **Экран входа (`TelegramAuthActivity`):** Ввод телефонного номера, выбор кода страны, получение проверочного кода Telegram и быстрый вход.
- **Боковое меню профиля (Drawer):** Аватар, имя, `@username`, телефон, переход в «Избранное», создание каналов и групп, пункт «Настройки Ggram».

### 💬 2. Главный экран списка чатов (`TelegramDialogsActivity`)
- **Умные вкладки (Smart Tabs):** Автоматическая сортировка `Все` • `Личные` • `Группы` • `Каналы` • `Боты` • `Непрочитанные`.
- **Интерактивные диалоги:** Аватарки, индикаторы статуса, время, счетчики непрочитанных в неоновом зеленом `#01ba53`.
- **Быстрые действия:** Кнопка «Пометить всё как прочитанное» в шапке, поиск по чатам, создание новых сообщений по кнопке FAB.

### ✉️ 3. Экран переписки (`TelegramChatActivity`)
- **Обмен сообщениями:** Пузыри сообщений в стиле Obsidian & Emerald, галочки прочтения (`ic_check_emerald_dots`).
- **Шпионский инспектор профилей:** Просмотр точного года создания аккаунта собеседника по его ID и проверка взаимного контакта в телефонной книге.
- **Интеграция с Anti-Recall:** Удаленные сообщения не пропадают, а помечаются `[Удалено]`. Измененные сообщения получают метку `[Изм.]` с историей всех версий.
- **Контекстное меню:** Копирование выделенного фрагмента, пересылка без автора в 1 клик.

## 🛠️ Встроенный премиум-комплекс Ggram
- **100% AdBlock:** Полное удаление спонсорских сообщений и рекламных постов каналов.
- **Режим невидимки (Ghost Suite):** Скрытое чтение, скрытый ввод текста, постоянный статус офлайн, скрытый просмотр историй.
- **Бесплатный Voice-to-Text:** Расшифровка голосовых заметок и видеокружочков без Telegram Premium.
- **Двойное дно:** Защита вторым ложным паролем и маскировка под «Калькулятор».
- **Turbo-загрузчик:** 4–8 потоковое ускоренное скачивание файлов до 4 ГБ.

## 🛠️ Сборка и релизы

### Автоматическая сборка через GitHub Actions
При каждом коммите или создании тега в репозитории автоматически запускается сборка APK в облаке GitHub Actions. Готовый APK доступен для скачивания во вкладках **Actions** и **Releases**.

### Локальная сборка
```bash
git clone https://github.com/grigfox43-hash/Ggram.git
cd Ggram
./gradlew assembleDebug
```
